# 🔐 Authora Authentication

A modern authentication application built with **React.js, Tailwind CSS, and REST API integration**.

Authora Authentication focuses on creating a clean, responsive, and user-friendly authentication experience with modern UI design, smooth animations, and a structured frontend architecture.

---

## 🌐 Live Demo

**Frontend:** https://jwt-authicatication-xvlc.vercel.app/

---

## 📌 Overview

**Authora Authentication** is an authentication-focused web application designed to practice and demonstrate modern frontend development concepts.

The project includes a polished authentication interface with registration and login flows, responsive layouts, Tailwind CSS styling, animations, and API integration.

The main focus of the project is building a professional authentication experience while connecting the frontend with authentication-related backend APIs.

## 🔄 Authentication Flow

```text
User
 │
 ▼
Authentication UI
 │
 ├── Register
 │
 └── Login
       │
       ▼
    REST API
       │
       ▼
Authentication Response
       │
       ▼
Authenticated User
```

The frontend communicates with the authentication API through REST requests and provides users with a simple and responsive authentication experience.

## 🏗️ Application Architecture

```text
Authora Authentication
│
├── Frontend
│   │
│   ├── React.js
│   ├── Tailwind CSS
│   ├── Authentication UI
│   ├── Components
│   └── API Integration
│
└── Backend API
    │
    └── Authentication Services
```

The application follows a separated frontend and backend architecture, allowing the React frontend to communicate with the authentication API through HTTP requests.

## 💻 Getting Started

### 1. Clone the Repository

```bash
git clone <your-repository-url>
```

### 2. Navigate to the Frontend

```bash
cd Frontend
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Start the Development Server

```bash
npm run dev
```

The application will run on the local development server provided by Vite.

---

## 🔑 Environment Variables

If the project requires environment variables, create a `.env` file in the frontend directory.

```env
VITE_API_URL=http://localhost:your_backend_port
```

> Keep environment variables private and never commit sensitive configuration to a public repository.
